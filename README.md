# NULL: A Development Board for Pentesters
NULL is a ESP32-S3 based PCB board with capabilities of infrared emulation, RFID transceiving, ARP-spoofing on WiFi Networks, and LoRa Puck capabilities. Developed with a mixture of the ESP-IDF development environment while also utilizing my CLI application DarkPing(under development) developed in Rust for more abstract components.
## What was the motivation for NULL? 
The origins of the development of NULL really came out of the intrigue of the flipper zero. I wanted to create a cheaper alternative to what seemed like an amazing development board for pentesting enthuastist. And, not only did I create a cheaper alternative for myself, but added an additional feature of a LoRA puck boosting the overall usefullness of the board.
